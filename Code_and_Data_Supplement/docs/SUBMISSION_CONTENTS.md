# Recommended AAAI-27 Uploads

1. Main paper PDF.
2. Supplementary Document PDF.
3. Official completed AAAI-27 reproducibility checklist as a separate upload.
4. This ZIP as the Code and Data Supplement.

Do not write that code or data "will be released after acceptance." The submission should contain the available code, configurations, schemas, expected results, and artifact limitations now.

The Code and Data Supplement ZIP now contains the exact NIH and COVIDx split definitions with author-specific paths removed. Do not upload the two original split ZIP files separately, because they contain local filesystem paths and are already incorporated here in anonymized form.
